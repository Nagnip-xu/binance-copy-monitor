开始前，
你可能想知道。

这里先回答最常见的几个问题。

还有问题？提个 Issue
真的可以 24 小时运行吗？

没有抢位时长限制。保持电脑接电、程序和专用 Edge 打开、登录有效、网络与代理稳定即可持续运行。屏幕可以熄灭；合盖、手动睡眠、关机或重启会打断运行。当前没有开机自动恢复监控。

能放在服务器上运行吗？

可以使用带图形桌面和 Microsoft Edge 的 Windows 服务器，仍需完成专用窗口登录并保持会话在线。当前不支持 Linux 无头自动跟单，也不提供 Docker 部署。

为什么设置了 0.1 秒，实际会更慢？

间隔之外还需要等待网络、平台响应与账号核验。请求串行执行，多个目标共用间隔；限流或查询故障也会增加等待。0.1 秒不代表每秒一定提交 10 次。

「结果核对中」还会继续抢位吗？

不会。上次创建可能已被平台执行，此时暂停所有新申请，只查询原申请结果。余额未变或尚未显示已跟单，都不能证明失败；不要删除提交记录来绕过核对。

金额上限 300 USDT，就是投入 300 吗？

不是。按平台最低金额投入：最低是 100，就申请投入 100；最低超过 300，就不加入。金额上限对每个组合分别生效，不是所有目标的总预算。资金需要在可用现货 USDT 中。

能保证抢到，或者保证收益吗？

不能。空位竞争、网络和平台风控都会影响结果。程序采用网页内部接口，规则可能变化。合约跟单使用真实资产，可能亏损；工具与币安官方无隶属关系。定额模式尚未完成实盘验证。
